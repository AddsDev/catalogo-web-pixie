# Catálogo PIXIE

Catálogo web de pruebas con piezas decorativas, filtros de productos y descarga del catálogo en PDF.

## Uso

Abre `index.html` en un navegador. Funciona sin conexión y no requiere instalación ni compilación.

Mantén la carpeta `assets` y el archivo `catalogo-pixie.pdf` junto a `index.html`.

Las imágenes son propuestas conceptuales y los precios son rangos sugeridos en pesos colombianos.
